# Titanic Machine Learning Module

## Overview

This module implements a complete machine learning workflow using the classic Titanic passenger dataset.

The objective is to build, evaluate, validate, and analyze classification models for predicting passenger survival.

The module covers:

- Dataset inspection and exploratory data analysis
- Data preprocessing
- Feature engineering
- Missing-value handling
- Numerical feature scaling
- Categorical feature encoding
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation
- Confusion matrices
- ROC-AUC analysis
- Stratified 5-fold cross-validation
- Class imbalance analysis
- SMOTE-based balancing
- Hyperparameter tuning
- Threshold tuning
- Final Random Forest evaluation
- Model persistence using Joblib
- Random Forest Out-of-Bag evaluation
- Fare regression analysis
- Residual analysis
- Heteroscedasticity testing
- Generated CSV results and visualization plots
