# Titanic Machine Learning Module

This module implements an end-to-end machine learning workflow using the
Kaggle Titanic dataset.

The objective is to predict whether a passenger survived the Titanic disaster
using passenger demographic, class, and travel-related information.

---

## 1. Dataset

The project uses the Titanic training dataset containing:

- 891 passengers
- 12 original columns
- `Survived` as the target variable

### Target Variable

```text
Survived
0 = Did not survive
1 = Survived
```
